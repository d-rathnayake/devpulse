## ✦ About

**DevPulse** is a terminal toolkit for Termux and Linux. View your GitHub profile, scan repo health, and check device info in a clean terminal UI.

## ⚡ Features

- 👤 **Developer profile**: GitHub profile details
- 🔍 **Repo scan**: stars, forks, open issues, last push
- 📱 **Device info**: OS, arch, disk, uptime
- 🌐 **Open profile**: open your GitHub profile in the browser
- 📐 **Any device**: the UI adapts to terminal width
- 🤖 **Bot**: GitHub Actions lints the scripts and welcomes new issues

## 🚀 Install (Termux)

```bash
git clone https://github.com/d-rathnayake/devpulse
cd devpulse
bash install.sh
```

After install, type `devpulse` anywhere to run it.

## 🧭 Usage

| Key | Action |
|---|---|
| `1` | Developer profile |
| `2` | Repo scan (`owner/name`) |
| `3` | Device info |
| `4` | Open GitHub profile |
| `0` | Exit |

## 📦 Requirements

- `git`
- `curl`

The install script installs these automatically.
